# MSNet

A simple, fast and secure VPN client for Android.

## Features

- ⚡ Fast connection
- 🔒 Secure VPN
- 🌍 Multiple protocols
- 📱 Modern Material Design UI
- 🔄 Import subscription links
- 🇸🇬 Low latency servers

## Supported Protocols

- VLESS
- VMess
- Trojan
- Shadowsocks
